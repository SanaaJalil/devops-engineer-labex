## What I Learned

| Operator | Purpose | Behaviour |
|----------|---------|-----------|
| `>` | Overwrite | Saves output to file, wipes previous content |
| `>>` | Append | Adds output to end of file, keeps history |
| `2>` | Error Redirect | Catches error messages |

---

## Key Takeaway
- `>` = overwrite (careful — deletes old content!)
- `>>` = append (safe — keeps history)
- `2>` = capture errors separately
