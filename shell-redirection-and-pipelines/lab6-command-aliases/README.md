# Lab 6: Command Aliases

## Course: Shell Redirection and Pipelines
**Path:** DevOps Engineer | **Level:** Beginner

---

## Lab Summary
Learned to create custom command shortcuts using Aliases!

---

## What I Learned

| Command | Purpose |
|---------|---------|
| `alias name='command'` | Create a new shortcut |
| `unalias name` | Delete a shortcut |

### Example
```bash
alias ll='ls -la'
alias cls='clear'
```

---

## Key Takeaway
- Aliases = your own custom commands
- Save time on commands you type often
- Customize Linux to work the way YOU work!
