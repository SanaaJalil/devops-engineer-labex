## What I Learned

| Command | Purpose |
|---------|---------|
| `sort` | Groups identical lines together |
| `uniq` | Filters out duplicates |
| `uniq -c` | Counts how many duplicates were found |

### The Classic Power Move
```bash
sort file.txt | uniq
```

---

## Key Takeaway
- `sort` first — groups identical lines together
- `uniq` second — removes duplicates from groups
- `uniq -c` = count occurrences
- `sort | uniq` is a classic Linux data processing combo!
