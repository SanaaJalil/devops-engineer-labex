## What I Learned

### The Three Data Streams

| Stream | Purpose | Default |
|--------|---------|---------|
| Standard Input (stdin) | Data going in | Keyboard |
| Standard Output (stdout) | Normal results | Screen |
| Standard Error (stderr) | Error messages | Screen |

---

## Key Takeaway
- Linux has 3 data streams: stdin, stdout, stderr
- By default both stdout and stderr appear on screen
- Next step: learn to separate them!
