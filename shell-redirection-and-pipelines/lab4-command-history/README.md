## Course: Shell Redirection and Pipelines
**Path:** DevOps Engineer | **Level:** Beginner

---

## Lab Summary
Linux remembers for you — no need to rely on memory!

---

## What I Learned

| Command | Purpose |
|---------|---------|
| `history` | Shows logbook of past commands |
| `!!` | Repeats the last command |
| `Ctrl+R` | Search through command history instantly |

---

## Key Takeaway
- `history` = your logbook
- `!!` = repeat last command
- `Ctrl+R` = search old commands
- Why type a long command twice when you can look it up?
