## What I Learned

### Commands Practiced

| Command | Purpose | Analogy |
|---------|---------|---------|
| `rm file` | Delete a file | The Shredder |
| `rmdir dir` | Delete an empty folder | Safe Removal |
| `rm -rf dir` | Delete folder with all contents | The Bulldozer |

---

## Key Takeaway
- `rm` = removes files only
- `rmdir` = removes empty directories only
- `rm -rf` = removes everything inside — use with caution!
- ⚠️ There is no recycle bin in Linux — deletion is permanent!
