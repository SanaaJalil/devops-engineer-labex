## What I Learned

### Commands Practiced

| Command | Purpose |
|---------|---------|
| `cp file new_file` | Copy a file |
| `cp -r dir new_dir` | Copy a directory recursively |
| `mv old new` | Rename a file |
| `mv file dir/` | Move a file into a folder |

---

## Key Takeaway
- `cp` = duplicates (original stays)
- `mv` = relocates or renames (original moves)
