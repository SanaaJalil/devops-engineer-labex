## What I Learned

### The Linux File System Tree

| Directory | Purpose |
|-----------|---------|
| `/` | Root — top of the entire hierarchy |
| `/bin` | Toolbox — where commands live |
| `/etc` | Settings — configuration files |
| `/home` | Personal Room — user files |

---

## Key Takeaway
- Linux files are organized in a single tree starting from `/`
- Commands are just files
- Settings are just text
- This transparency makes Linux powerful!
