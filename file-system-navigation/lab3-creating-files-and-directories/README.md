## What I Learned

### Commands Practiced

| Command | Purpose |
|---------|---------|
| `touch filename` | Creates an empty file or updates timestamp |
| `mkdir directoryname` | Creates a new directory |
| `mkdir -p path/to/directory` | Creates full path including missing parents |

---

## Key Takeaway
- `touch` = create empty files
- `mkdir` = create directories
- `mkdir -p` = create nested directories in one command
