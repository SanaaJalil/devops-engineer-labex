# Lab 2: Listing Files

## Course: File System Navigation and File Operations
**Path:** DevOps Engineer | **Level:** Beginner

---

## What I Learned

| Command | Purpose |
|---------|---------|
| `ls` | Basic list |
| `ls -l` | Long details - permissions, owners, size |
| `ls -a` | Show hidden files |
| `ls -R` | Recursive list |
| `ls -la` | Details + hidden files combined |

---

## Key Takeaway
- `-l` = ID cards for files
- `-a` = see hidden dotfiles
- `-R` = see everything deep inside
