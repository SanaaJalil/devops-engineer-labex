## What I Learned

### Navigation Toolbox

| Command | Purpose | Analogy |
|---------|---------|---------|
| `cd ~` | Go to home directory | Teleport Home |
| `cd /` | Go to root directory | Go to the Root |
| `cd folder` | Enter a folder | Step into a folder (Relative) |
| `cd ..` | Go to parent directory | Step Up |
| `cd -` | Go to previous location | Go Back |

---

## Key Takeaway
- Absolute paths start from `/`
- Relative paths start from where you are
- These shortcuts are faster than any mouse navigation!
