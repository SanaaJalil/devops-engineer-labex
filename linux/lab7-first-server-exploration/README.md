## What I Learned

### Core Orientation Skills

| Skill | Command | Purpose |
|-------|---------|---------|
| Identity Verification | `whoami` | Ensure accountability |
| Host Verification | `hostname` | Ensure you are on the right server |
| Absolute Navigation | `cd /path` | Precision navigation |
| Relative Navigation | `cd ..` / `cd path` | Speed and efficiency |
| Documentation | `man` | Find answers independently |

---

## Key Takeaway
- Always verify WHO you are and WHERE you are on a server
- Use absolute paths for precision
- Use relative paths for speed
- `man` = your best friend on any server
