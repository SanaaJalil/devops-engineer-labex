## What I Learned

### Commands Practiced

| Command | Purpose |
|---------|---------|
| `man <command>` | Full documentation for any command |
| `<command> --help` | Quick syntax reminder |

### Inside Man Pages
| Key | Action |
|-----|--------|
| `/keyword` | Search for a keyword |
| `q` | Quit the man page |

---

## Key Takeaway
- You don't need to memorize thousands of flags
- Just remember how to ask for help!
- `man` = deep dive documentation
- `--help` = quick reference
