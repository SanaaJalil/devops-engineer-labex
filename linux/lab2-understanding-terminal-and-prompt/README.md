## What I Learned

### 1. Reading the Prompt
| Part | Meaning |
|------|---------|
| `labex` | Current username |
| `project` | Current directory |
| `$` | Standard user |
| `#` | Root user |

### 2. Commands Practiced

| Command | Purpose |
|---------|---------|
| `echo "text"` | Print text to screen |
| `echo $USER` | Display current username |
| `clear` | Clear the terminal screen |
| `Ctrl + L` | Shortcut to clear screen |

---

## Key Takeaway
These simple skills are used every day by Linux professionals.
