## What I Learned

### 1. Terminal Access
How to interact with the command line interface (CLI).

### 2. Prompts
| Prompt | Means |
|--------|-------|
| `$` | Standard user |
| `#` | Root user (superuser) |

### 3. Commands Practiced

| Command | Purpose | My Output |
|---------|---------|-----------|
| `whoami` | Check current username | `labex` |
| `pwd` | Check current directory | `/home/labex/project` |
| `hostname` | Identify the machine | `6a29a5e3402a3d67adf164f0` |
| `sudo -i` | Switch to root user | prompt changes to `#` |
| `exit` | Exit root / logout | returns to `$` |

---

## Key Takeaway
These basic commands are the foundation for all future Linux operations.
