## What I Learned

### Commands Practiced

| Command | Purpose | Analogy |
|---------|---------|---------|
| `pwd` | Shows your current location | GPS — tells you where you are |
| `cd` | Move to another directory | Legs — moves you around |

### Absolute Paths
| Concept | Meaning | Example |
|---------|---------|---------|
| Absolute Path | Full path starting from root `/` | `/home/labex/project` |

---

## Key Takeaway
- `pwd` = "Where am I?"
- `cd` = "Take me to..."
- Absolute paths always start with `/`
