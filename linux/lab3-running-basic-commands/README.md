## What I Learned

### 1. Success - Running a Valid Command
| Command | Purpose | Example Output |
|---------|---------|----------------|
| `date` | Shows current date and time | `Wed Jun 10 10:23:01 UTC 2026` |

### 2. Failure - Command Not Found
| Error | Cause | Fix |
|-------|-------|-----|
| `command not found` | Typo in command name | Check spelling and retry |

### 3. Closure - Ending a Session
| Command | Purpose |
|---------|---------|
| `exit` | Properly ends your terminal session |

---

## Key Takeaway
- Valid commands return useful output
- Errors are usually just typos — read the message and fix it
- Always exit your session properly when done
