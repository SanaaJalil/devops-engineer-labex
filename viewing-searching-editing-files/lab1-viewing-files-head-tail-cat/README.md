# Lab 1: Viewing Files with Head, Tail and Cat

## Course: Viewing, Searching, and Editing Files
**Path:** DevOps Engineer | **Level:** Beginner

---

## Lab Summary
Learned the basic toolkit for examining files in Linux!

---

## What I Learned

| Command | Purpose | Best For |
|---------|---------|---------|
| `cat` | Reads the whole file | Small files |
| `head` | Reads the beginning | Quick checks |
| `tail` | Reads the end | Logs |
| `tail -f` | Watches file in real-time | Live logs |

---

## Key Takeaway
These commands answer the question: "What is inside this file?"
