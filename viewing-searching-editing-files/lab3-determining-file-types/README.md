# Lab 3: Determining File Types

## Course: Viewing, Searching, and Editing Files
**Path:** DevOps Engineer | **Level:** Beginner

---

## Lab Summary
Learned to look past the label and see the true nature of files!

---

## What I Learned

| Concept | Details |
|---------|---------|
| `file filename` | Uncovers the true type of any file |
| Extensions lie | `.jpg` doesn't always mean image |
| No extension | Linux doesn't need extensions to identify files |

---

## Key Takeaway
- Never trust file extensions blindly
- Use `file` command to know the truth
- Linux identifies files by content, not name!
