## What I Learned

### Vim Commands

| Command | Purpose |
|---------|---------|
| `vim filename` | Open the file in Vim |
| `i` | Insert Mode — start typing |
| `Esc` | Normal Mode — stop typing |
| `dd` | Delete a line |
| `:wq` | Write and Quit (save and exit) |

---

## Key Takeaway
- Vim has modes — always know which mode you are in!
- `i` to type, `Esc` to stop, `:wq` to save and exit
- Muscle memory makes you a true Linux power user!
