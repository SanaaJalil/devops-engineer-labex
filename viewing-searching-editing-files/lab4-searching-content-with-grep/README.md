## What I Learned

| Command | Purpose |
|---------|---------|
| `grep "text" file` | Find the text in a file |
| `grep -i "text" file` | Find text regardless of case |
| `grep -v "text" file` | Hide lines containing the text |

---

## Key Takeaway
- `grep` = your search engine for files
- `-i` = case insensitive search
- `-v` = invert search (exclude matches)
- Combine them to slice and dice any text file!
