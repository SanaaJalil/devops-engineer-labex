## What I Learned

### The Nano Cycle

| Step | Action |
|------|--------|
| 1. Open | `nano filename` |
| 2. Edit | Type and write |
| 3. Save | `Ctrl+O` then `Enter` |
| 4. Exit | `Ctrl+X` |

## Key Takeaway
- Nano allows you to fix servers from anywhere in the world
- Just a keyboard is all you need!
