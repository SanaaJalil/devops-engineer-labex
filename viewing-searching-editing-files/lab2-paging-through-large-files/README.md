## What I Learned

### The `less` Command

| Action | Key |
|--------|-----|
| Open file | `less filename` |
| Flip pages | `Spacebar` |
| Fine-tune movement | Arrow keys |
| Search for keyword | `/keyword` |
| Next search match | `n` |
| Quit | `q` |

---

## Key Takeaway
- No file is too big with `less`
- Works comfortably on tiny notes or gigabyte-sized logs!
