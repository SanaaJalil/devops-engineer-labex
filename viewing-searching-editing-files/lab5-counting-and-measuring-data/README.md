# Lab 5: Counting and Measuring Data

## Course: Viewing, Searching, and Editing Files
**Path:** DevOps Engineer | **Level:** Beginner

---

## Lab Summary
Learned to use the Linux accountant - `wc`!

---

## What I Learned

| Command | Purpose |
|---------|---------|
| `wc -l` | Count lines/records |
| `wc -w` | Count words |
| `wc -c` | Count size/bytes |

---

## Key Takeaway
- `wc` = your Linux accountant
- Use it whenever you need "How many?" or "How big?"
