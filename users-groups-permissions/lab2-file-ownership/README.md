# Lab 2: File Ownership and Group Ownership

## Summary

- Every file has both a **User Owner** and a **Group Owner**.
- `ls -l` — view ownership labels on files and directories.
- `chown` — change the user owner of a file.
- `chgrp` — change the group owner of a file.

Just like in real life, you can only give away what belongs to you — but sometimes you need `sudo` to transfer important items!
