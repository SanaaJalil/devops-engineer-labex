# Lab 2: The PATH Variable

## Course: Shell Environment and Variables
**Path:** DevOps Engineer | **Level:** Beginner

---

## Lab Summary
Learned how Linux finds commands using the PATH variable!

---

## What I Learned

| Concept | Details |
|---------|---------|
| `$PATH` | A map of folders where system looks for programs |
| `which command` | Shows exact file that runs when you type a command |
| `./` | Required to run scripts in current directory |

---

## Key Takeaway
- `$PATH` = list of folders Linux searches for commands
- `which` = find where a command lives
- Current folder is NOT in PATH by default
- Always use `./script.sh` to run local scripts!
