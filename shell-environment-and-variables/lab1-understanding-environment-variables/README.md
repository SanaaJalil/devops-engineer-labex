## What I Learned

| Concept | Details |
|---------|---------|
| Variables | Containers that hold information |
| `$` sign | Used to read the value inside a variable |
| `$USER` | Current username |
| `$SHELL` | The shell being used (`/bin/zsh` or `/bin/bash`) |
| `env` | Shows entire list of system settings |

---

## Key Takeaway
- Variables = containers for information
- Use `$` to read a variable's value
- `env` = see all environment settings
- These are the foundation of Linux configuration!
