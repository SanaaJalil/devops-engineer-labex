# Lab 4: Shell Configuration Persistence

## Course: Shell Environment and Variables
**Path:** DevOps Engineer | **Level:** Beginner

---

## Lab Summary
Learned how to permanently personalize the Linux environment!

---

## What I Learned

| Concept | Details |
|---------|---------|
| `.zshrc` | Config file for Zsh shell |
| `.bashrc` | Config file for Bash shell |
| `source ~/.bashrc` | Apply changes without restarting terminal |

### How Persistence Works
| Type | Lasts |
|------|-------|
| Terminal session change | Until terminal closes |
| Saved to `.bashrc`/`.zshrc` | Forever |

---

## Key Takeaway
- Changes in terminal are temporary unless saved to config files
- `source` = apply changes immediately without restart
- Different shells use different config files!
